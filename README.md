### EEC — Project Portfolio Planning & Monitoring System

A full-stack project portfolio planning and monitoring information system designed for the EEC Transport Sector Planning & Monitoring Team.

The platform helps management monitor project performance, identify delays, understand portfolio health, track risks, and support informed decisions.

**Key capabilities**

- Portfolio progress monitoring.
- Planned vs. actual performance tracking.
- Schedule and financial progress monitoring.
- Project health indicators.
- Risk and issue tracking.
- Management interventions and recovery planning.

**Technology Stack**

`React 18` · `Vite` · `Chakra UI` · `Node.js` · `Express.js` · `PostgreSQL` · `Sequelize` · `JWT`
